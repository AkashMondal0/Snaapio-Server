# Grafana Dashboard Import Instructions

To import the dashboard into Grafana:

1. Open your Grafana instance.
2. Navigate to the **Dashboards** section.
3. Click on **Import**.
4. Upload the provided JSON file:

	- **File Name**: `grafana-dashboard.json`

5. Select the appropriate data sources for Prometheus and Loki when prompted.
6. Click **Import** to complete the process.
